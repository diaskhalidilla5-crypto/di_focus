# DI Focus — Android App (Kotlin + Jetpack Compose)

**DI Focus** — умный блокировщик телефона по расписанию с ИИ-проверкой (Gemini API), встроенным решением учебных задач из файлов, строгим ИИ-тьютором (отвечает только по теме текущего задания) и защищенным экстренным выходом.

---

## Как получить готовый `.apk` файл БЕЗ установки Android Studio (за 3 минуты через GitHub)

Так как в проект уже встроен автоматический сборщик **GitHub Actions** (`.github/workflows/build-apk.yml`), тебе даже не нужно устанавливать тяжелую Android Studio на компьютер:

1. Зарегистрируйся или войди на [GitHub.com](https://github.com) (можно даже с телефона).
2. Создай новый репозиторий (например, `di-focus-app`, можно сделать его `Private`).
3. Загрузи все файлы из этого архива в репозиторий (кнопка **Add file -> Upload files**).
4. Перейди во вкладку **Actions** сверху — ты увидишь, что сборка **Build DI Focus APK** запустилась автоматически!
5. Подожди ~2–3 минуты, пока значок станет зеленым , открой завершенную сборку и внизу в разделе **Artifacts** скачай готовый **`DI-Focus-Debug-APK`**.
6. Распакуй `app-debug.apk`, скинь себе и друзьям в Telegram и установи на телефон!

*(А если захочешь редактировать код на компьютере — просто открой эту папку в **Android Studio** и нажми `Build -> Build Bundle(s) / APK(s) -> Build APK(s)`).*

## Что умеет DI Focus

1. **Планирование по дням недели и датам**:
   Выбираешь дни и добавляешь задачи двух типов:
   - **Реальное дело (Фото-пруф)** — уборка, спортзал, конспект, прогулка. Разблокируется только после живого снимка с камеры, который проверяет Gemini Vision.
   - **Учебное задание (Файлы + Решение в приложении)** — прикрепляешь файл с задачами (`.txt`, `.md`, `.pdf`, фото или текст задач) и **опционально отдельный файл с ответами/ключами** (виден только нейросети для точной сверки!). Решаешь задачи прямо на экране телефона и отправляешь на проверку ИИ.
2. **Строгий ИИ-Тьютор (Чат по заданию)**:
   Если не понимаешь, как решить задачу из прикрепленного файла, прямо внутри карточки задачи есть чат с нейросетью. Системный промпт жестко ограничивает ИИ:
   - Он объясняет теорию и дает подсказки **только по текущему файлу заданий**.
   - Он **не выдает готовый ответ напрямую**, а направляет к решению.
   - На любые вопросы не по теме задания (игры, фильмы, сторонние темы) он вежливо отказывает и возвращает к задаче.
3. **Настоящая блокировка приложений (`FocusBlockerService`)**:
   Использует `AccessibilityService`. Как только ты открываешь TikTok, Instagram, YouTube, Telegram или игры при невыполненных задачах на сегодня — поверх мгновенно открывается экран блокировки DI Focus.
4. **Экстренный выход (Emergency Bypass)**:
   Разблокировка на 5 минут (1 раз в сутки), для активации которой нужно **непрерывно удерживать кнопку пальцем 15 секунд**.
